
Customer Churn Analysis Dashboard

Project Overview

This project analyzes customer churn patterns for a telecom company using SQL, Power BI, Excel, and dimensional data modeling. The objective is to identify churn drivers, estimate revenue at risk, and recommend retention strategies using data-driven insights.

Dataset

- Total Customers: 7,043
- Data Model: Star Schema
- Tables:
  - dim_customers
  - dim_services
  - fact_billing
  - fact_support

Key KPIs

KPI| Value
Churn Rate| 26.5%
Retention Rate| 73.5%
Monthly Revenue Loss| $139K
Avg Tenure at Churn| 17.9 Months
CLV at Risk| $2.9M

Business Insights

- Month-to-month customers churn at 15× the rate of two-year contract customers.
- Nearly half of all churn occurs within the first 12 months.
- Customers with multiple support tickets have significantly higher churn probability.

Tools Used

- SQL
- Power BI
- Excel
- Data Modeling
- Business Intelligence

Business Recommendations

1. Promote long-term contracts through retention incentives.
2. Launch early-tenure engagement programs.
3. Improve customer support resolution processes.
4. Implement churn risk monitoring dashboards.
5. Target high-risk customers with retention campaigns.

Project Outcome

The proposed retention strategy could reduce churn from 26.5% to approximately 16%, protecting an estimated $1.1M in annual recurring revenue.
